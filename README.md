# 血红 (BloodySpeed)

一款以「人体内部世界」为舞台的隐喻式短篇游戏原型。玩家扮演最后一名戍卫者，在身体内部世界「赤野」中穿行，通过亲身体验理解女性更年期的心路历程。

## 项目定位

- **类型**：2D 横版解谜平台（参考《Gris》）
- **主题**：用隐喻让玩家——尤其是男性玩家——理解更年期，而非直白的说教
- **时长**：1 小时以内
- **核心原则**：症状是「内部机制」而非「外部敌人」，无击杀，只有穿越、安抚、共存

## 技术栈

- Godot 4.6（Forward Plus 渲染）
- GDScript
- 剪影 / 极简几何美术（当前为白盒占位）

## 当前进度（原型阶段）

已实现：

- 玩家控制器：左右移动、跳跃
- 年轻形态三技能：二段跳、疾风冲刺、锋锐切割（含空中下落攻击变体）
- 成熟形态：滑翔（替代二段跳）；洞察、安抚暂未实现
- 形态切换，年轻 = 白色 / 成熟 = 黑色
- 长暖乡白盒关卡（程序化生成，含教学平台与「一跃涧」断裂口）

## 操作说明

| 按键 | 动作 |
|------|------|
| ← / → 或 A / D | 左右移动 |
| 空格 | 跳跃 / 二段跳（年轻）；滑翔（成熟，空中按住） |
| Shift | 疾风冲刺 |
| F | 锋锐切割（空中使用 = 垂直向下下落攻击） |
| T | 切换形态（年轻 / 成熟） |

## 运行方式

1. 用 Godot 4.6 打开本项目
2. 按 `F6` 运行当前场景
